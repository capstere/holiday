# Task 004 — Three.js first-person prototype

Build the first real 3D prototype from extracted geometry.

## Requirements

- Use metric world units.
- Player eye height around 1.65 m.
- WASD + mouse pointer lock.
- Walls generated from wall segments.
- Door openings remain passable.
- Add top-down debug minimap.

## Acceptance criteria

- Player can walk through a small verified zone.
- Player cannot walk through walls.
- Doorways are passable.
- Debug overlay shows current room/zone if available.
