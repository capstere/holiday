# Task 003 — Door portal annotation

Create a door annotation mode.

## Requirements

- User can select two points across a door opening.
- Assign door id and connected rooms.
- Store width and approximate normal direction.
- Door arc/swing must not be exported as wall geometry.

## Acceptance criteria

- At least one door in Z3 can be annotated and exported.
- Export includes door center, width and connected room ids.
